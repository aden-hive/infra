VM display (noVNC)

Live noVNC stream of the workspace VM, served through client-proxy at 6080-<sandboxId>.vm.open-hive.com. The embed token has a 10-minute TTL — click Refresh in the Workspace card above to mint a new one. If the iframe is blank, try Open in new tab (some browsers / browser extensions block third-party-host iframes).
